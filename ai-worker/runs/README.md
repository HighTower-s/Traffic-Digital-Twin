# ชุดข้อมูลสำเร็จรูป — เล่นซ้ำโดยไม่ต้องรัน YOLO ใหม่

`python -m src.main` เขียนผลลง `data/output_results/` ที่เดียวเสมอ และ **เขียนทับทุกครั้งที่รัน**
โฟลเดอร์นี้คือที่เก็บชุดข้อมูลที่วิเคราะห์เสร็จแล้ว เอาไว้เล่นซ้ำได้เรื่อย ๆ ในไม่กี่วินาที
แทนที่จะรัน YOLO ทั้งคลิปใหม่ทุกครั้ง (คลิป 3.4 นาที = หลายนาที)

ไฟล์เป็น text ล้วน ชุดละราว 30 KB จึง **commit เข้า git ได้** — `git pull` แล้วได้ชุดข้อมูลเลย

---

## ใช้ยังไง

```bash
python -m src.replay --from runs/event-2_slow-moving --backend   # ส่งเข้า backend ตามจังหวะเวลาจริง
python -m src.replay --from runs/event-2_slow-moving --fast      # ดูผลเฉย ๆ ไม่หน่วงเวลา
```

ทุกครั้งที่ส่ง `--backend` ไฟล์ใน `backend/data/output/` และตัวนับบน dashboard
จะถูกล้างก่อน ผลที่เห็นจึงเป็นของรอบนั้นรอบเดียวเสมอ รันซ้ำกี่รอบก็ไม่บวกทบ

**ถ้าทำฝั่ง Unity** ต้องใช้แค่นี้ — เปิด backend (`cd backend && npm run dev`) แล้วสั่งคำสั่งแรก
ไม่ต้องมีไฟล์วิดีโอ ไม่ต้องลง YOLO ไม่ต้องมี GPU

`--from` อ่าน 3 ไฟล์จากในโฟลเดอร์ จะใส่ `--config` / `--file` / `--state-file` ซ้ำไม่ได้ (error)

## ชุดที่มี

| โฟลเดอร์ | คลิป | ข้อมูล | ผลตัดสิน |
|---|---|---|---|
| `event-2_slow-moving` | `event-2.mp4` · กล้อง KMITL · 198 วินาที | spawn 100 คัน · 10 ช่วง | `normal` 50% · `slow_moving` 50% |

ยังไม่มีชุดที่เป็น `high_density` หรือ `standstill` — **เพราะยังไม่มีคลิปที่ถนนติดขนาดนั้นจริง
ไม่ใช่เพราะเกณฑ์ตั้งผิด** ต้องถ่ายเพิ่มช่วงเร่งด่วน

## ข้างในมีอะไร

```
event-2_slow-moving/
├── config.yaml          ← โซน + เกณฑ์ตัดสินที่ใช้กับชุดนี้
├── events.jsonl         ← รถที่ข้ามเส้น 1 คัน = 1 บรรทัด
└── traffic_state.jsonl  ← ผลวัดต่อช่วง 20 วินาที (ยังไม่ตัดสิน — replay ตัดสินตอนเล่น)
```

**`config.yaml` ต้องอยู่ด้วยเสมอ** เพราะ `occupancy` ขึ้นกับขนาดกรอบที่วาดและมุมกล้อง
เกณฑ์จึงย้ายข้ามชุดไม่ได้ — `event-1` วัดได้ 14–17 ส่วน `event-2` วัดได้ 0–11 ทั้งที่รถติดพอกัน
ถ้าไม่มีไฟล์นี้ `--from` จะ error ไม่ถอยไปใช้ค่าเริ่มต้นเงียบ ๆ

ไม่เก็บ payload ฝั่ง backend (`spawn_vehicle.jsonl` ฯลฯ) เพราะ `--from ... --backend`
สร้างใหม่ได้ทุกเมื่อ — จะได้ไม่มี 2 เวอร์ชันที่ไม่ตรงกัน

## เพิ่มชุดใหม่

หลังรัน `python -m src.main --config configs/<มุมกล้อง>.yaml` เสร็จ:

```bash
mkdir -p runs/<คลิป>_<โน้ต>
cp data/output_results/events.jsonl data/output_results/traffic_state.jsonl runs/<คลิป>_<โน้ต>/
cp configs/<มุมกล้อง>.yaml runs/<คลิป>_<โน้ต>/config.yaml
```

ตั้งชื่อ `<คลิป>_<โน้ต>` เช่น `event-2_slow-moving`, `traffic-5_normal` — เรียงแล้วรอบของคลิป
เดียวกันอยู่ติดกัน เทียบผลง่าย และโน้ตบอกได้ว่ารอบนี้ต่างจากรอบอื่นตรงไหน

**ก็อปให้ครบทั้ง 3 ไฟล์** รอบถัดไปที่รัน `main` จะทับ `data/output_results/` ทันที

เสร็จแล้วเพิ่มแถวในตาราง "ชุดที่มี" ข้างบนด้วย
